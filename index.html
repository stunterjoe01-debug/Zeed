Purpose of ZEED

ZEED is a Private AI Tool Vault. It allows you to build, store, and run custom applications (Seeds) without needing a complex server. Everything stays rooted in your browser.

How to use:

  1. Get a "Seed" (JSON code) from an AI.
  2. Plant it in The Forge.
  3. Launch it from The Vault.
  4. Add API keys in Settings if the tool needs AI power.
